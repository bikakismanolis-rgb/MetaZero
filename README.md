# Καθαρό

Web εφαρμογή (PWA) που σβήνει τα κρυφά στοιχεία από αρχεία πριν τα μοιραστείς: τοποθεσία GPS, μοντέλο και σειριακό αριθμό συσκευής, ημερομηνίες, ονόματα, διαδρομές από τον υπολογιστή, ονόματα σε σχόλια.

Όλη η δουλειά γίνεται μέσα στον browser. Δεν υπάρχει server, τα αρχεία δεν ανεβαίνουν πουθενά, και μετά την πρώτη φόρτωση δουλεύει χωρίς internet.

## Τι υποστηρίζει

| Τύπος | Μορφές | Τι αφαιρείται |
|---|---|---|
| Φωτογραφίες | JPEG, PNG, WebP, GIF, HEIC, AVIF | EXIF, GPS, XMP, IPTC, MakerNotes, μικρογραφίες, κρυφές εικόνες, δεδομένα μετά το τέλος του αρχείου, προσωπικά προφίλ χρωμάτων, prompts AI |
| Βίντεο / ήχος | MP4, MOV, M4A, MP3 | τοποθεσία, συσκευή, ημερομηνίες, Apple/Android κλειδιά, iTunes/ID3 tags, XMP, C2PA |
| PDF | PDF | πληροφορίες εγγράφου, XMP, κωδικός εγγράφου, παλιές εκδόσεις, ονόματα σε σχόλια, EXIF των φωτογραφιών μέσα στο PDF |
| Office | DOCX, XLSX, PPTX, ODT, ODS, ODP | συντάκτες, εταιρεία, ημερομηνίες, χρόνος επεξεργασίας, προσαρμοσμένα πεδία, μικρογραφία, διαδρομή προτύπου/αρχείου, εκτυπωτής, rsid, ονόματα σε σχόλια και αλλαγές, EXIF των φωτογραφιών μέσα στο έγγραφο, ημερομηνίες του ZIP |

Οι εικόνες και τα βίντεο **δεν ξανασυμπιέζονται**: βγαίνουν ίδια pixel προς pixel. Κρατιούνται μόνο ο προσανατολισμός της φωτογραφίας και τα τυπικά προφίλ χρωμάτων (sRGB, Display P3), για να μη φαίνεται στραβή ή με λάθος χρώματα.

Κάθε αρχείο περνάει δεύτερη φορά από τον καθαριστή για να επιβεβαιωθεί ότι δεν έμεινε τίποτα.

### Τι δεν κάνει

- Δεν αλλάζει το ορατό περιεχόμενο (πρόσωπα, πινακίδες, κείμενο). Προειδοποιεί για σημειώσεις ομιλητή, κρυφά φύλλα, παρακολούθηση αλλαγών, σχόλια.
- Δεν υποστηρίζει τα παλιά .doc/.xls/.ppt, ούτε αρχεία ZIP.
- Ροές τηλεμετρίας σε βίντεο (GoPro, DJI, κάμερες 360°) δεν αφαιρούνται. Η εφαρμογή το λέει όταν τις βρει.

## Πώς τρέχει

Δεν χρειάζεται build. Είναι στατικά αρχεία:

```bash
npm run serve
```

Μετά άνοιξε `http://localhost:8080`. Για δοκιμή στο κινητό χρειάζεται HTTPS (π.χ. ανέβασμα σε Vercel, Netlify, GitHub Pages ή Cloudflare Pages). Αρκεί να ανέβει ο φάκελος όπως είναι.

Στο Android, μετά την «Εγκατάσταση», η εφαρμογή εμφανίζεται στο μενού **Κοινοποίηση**.

## Δομή

```
index.html, styles.css, app.js   οθόνη της εφαρμογής
sw.js, manifest.webmanifest      λειτουργία χωρίς internet, εγκατάσταση, share target
src/clean.js                     αναγνώριση τύπου (από τα bytes) και δεύτερος έλεγχος
src/jpeg.js png.js webp.js gif.js
src/isobmff.js                   MP4/MOV/M4A/HEIC/AVIF (αλλάζει μόνο τα κουτιά με metadata)
src/mp3.js pdf.js office.js
src/exif.js xmp.js iptc.js       ανάγνωση των ευρημάτων για να τα δει ο χρήστης
vendor/                          pdf-lib 1.17.1, JSZip 3.10.1 (φορτώνονται μόνο όταν χρειαστούν)
```

## Έλεγχοι

```bash
npm run fixtures   # φτιάχνει αρχεία γεμάτα metadata (θέλει exiftool, ffmpeg, heif-enc, LibreOffice)
npm test           # καθαρίζει και ελέγχει ανεξάρτητα με exiftool, ffmpeg, qpdf, LibreOffice
node tests/e2e.cjs # δοκιμή στον browser (Playwright), με τον server να τρέχει
```

Ο ανεξάρτητος έλεγχος (`tests/verify.py`) ψάχνει τα ευαίσθητα στοιχεία σε κάθε byte του αρχείου (και μέσα σε ZIP και αποσυμπιεσμένα PDF). Ελέγχει επίσης ότι το αρχείο ανοίγει και ότι εικόνα, βίντεο και ήχος είναι ίδια με το αρχικό.
